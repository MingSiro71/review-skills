# 指摘してはいけないもの

配布レビューの各サブエージェントと評価担当は、このファイルを読み、該当するものを報告しない。
評価担当は、渡された指摘がここに該当していないかも確認する。

- 変更前から存在していた問題
- バグに見えるが実際にはバグでないもの
- シニアエンジニアなら指摘しない些末な nit
- linter / typechecker / compiler が捕まえるもの（import 漏れ、型エラー、テストの失敗、整形の問題を含む。
  CI で別途走るため、自分で build や typecheck を実行して確認する必要もない）
- ルールに反しているが、コード上で明示的に黙らせているもの（lint ignore コメント等）
- 意図的と思われる、あるいは変更の本筋に直接関係する挙動の変化
- 実在する問題だが、この変更で触っていない行にあるもの
